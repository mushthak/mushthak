# Mushthak Ebrahim

I’m an iOS Lead building reliable, testable Apple-platform software with Swift and SwiftUI. My work focuses on pragmatic architecture, TDD, Swift concurrency, and engineering systems that remain clear as products grow.

I’m also expanding into AI-assisted and agentic development—bringing the same emphasis on explicit boundaries, evaluation, human review, and maintainable delivery.

## What I work on

- **iOS & SwiftUI:** modern Apple-platform experiences built with native frameworks
- **Architecture:** modular design, composition roots, dependency injection, and unidirectional state flow
- **Quality:** test-driven development, CI, readable specifications, and reviewable changes
- **Concurrency:** async/await, actor isolation, and Swift 6 strict-concurrency practices
- **Agentic engineering:** practical workflows where humans retain ownership of design, verification, and release decisions
